# NE Quick Start — SteamWorld Heist 2

Requires **NE Mod Loader & Manager** 1.2+ and the current Steam or GOG version of the game.

Gets you into the game faster: **skips the logo movie** at start (setting in the loader).
Loading the last save right away is planned for a later version.

## How it works
Patches `SteamWorld Heist 2.exe`: the logo movie list is treated as empty. The loader keeps a backup of the original exe, checks the
exe version before patching and rebuilds from the backup on every install. If the game is a different build, the mod
refuses to install instead of breaking anything.

Uninstall: untick it and click Apply, or *Restore original files*.

## Install
Unpack into the game folder (`SteamWorld Heist 2\Mods\QuickStart\mod.json`) or use Vortex, then enable it in NE Mod
Loader & Manager and click **Apply to game**.

# NE Quick Start — по-русски

Нужен **NE Mod Loader & Manager** 1.2+ и текущая Steam- или GOG-версия игры.

Быстрее в игру: **пропускает ролик с логотипом** при запуске (настройка в загрузчике).
Сразу загружать последнее сохранение — в планах на следующую версию.

## Как это работает
Патчит `SteamWorld Heist 2.exe`: список роликов-логотипов считается пустым. Загрузчик хранит бэкап оригинального exe,
проверяет версию перед патчем и каждый раз собирает из бэкапа. Если версия игры другая — мод не установится, а не
сломает игру.

Удаление: снимите галочку и нажмите Apply или *Restore original files*.

## Установка
Распакуйте в папку игры (`SteamWorld Heist 2\Mods\QuickStart\mod.json`) или через Vortex, включите в NE Mod Loader &
Manager и нажмите **Apply to game**.

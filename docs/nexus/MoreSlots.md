# NE More Save Slots

## Name
```text
NE More Save Slots
```

## Description (plain text, max 350 characters)
```text
4 to 10 save slots in the SteamWorld Heist 2 main menu instead of 3 (default 6). Keep a randomizer run, a hardcore run and a normal playthrough side by side. Turning the mod off never deletes the extra saves.
```

```text
[size=5][b]Description[/b][/size]
SteamWorld Heist 2 has only 3 save slots. NE More Save Slots raises that to anything from 4 to 10 (default 6), so you can keep several runs side by side — a randomizer seed, a hardcore run and your normal playthrough.

[size=5][b]Installation instructions[/b][/size]
[list=1]
[*]Install [b]NE Mod Loader & Manager[/b] first.
[*]Unpack this archive into the game folder (you get [i]SteamWorld Heist 2\Mods\MoreSlots\mod.json[/i]), or install it with Vortex or by dragging the .zip onto the loader.
[*]Close the game, open SWH2ModLoader.exe, tick [b]NE More Save Slots[/b], choose the number of slots and click [b]Apply to game[/b].
[/list]
[b]Uninstall:[/b] untick it and click Apply, or click Restore original files. Steam's "Verify integrity of game files" also restores the exe.

[size=5][b]Main features[/b][/size]
[list]
[*][b]4–10 save slots[/b] in the main menu (setting in the loader, default 6).
[*]With more than 6 slots the slot buttons get shorter so they all fit on the screen.
[*][b]Your saves are safe[/b]: turning the mod off or lowering the number deletes nothing — saves in the extra slots stay on disk, the game just doesn't show them until the mod is back on.
[*]Safe patching: the loader keeps a backup of the original exe, checks the game version before patching and refuses to install on an unknown build instead of breaking anything.
[/list]
Tip: the loader's [b]Save banks[/b] can also store any slot as a named copy and put it back later — even without this mod.

[size=5][b]Requirements[/b][/size]
[list]
[*][b]NE Mod Loader & Manager[/b] 1.0 or newer.
[*]The current Steam version of SteamWorld Heist 2 (the mod patches the game exe).
[/list]
Works together with my other mods. Source code: [url=https://github.com/nerdError/SteamWorldHeist2-Mods]GitHub[/url].
```

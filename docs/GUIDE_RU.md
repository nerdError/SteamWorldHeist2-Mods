SWH2 MOD LOADER + МОДЫ — ИНСТРУКЦИЯ
====================================

Что в этой папке
----------------
  SWH2ModLoader\SWH2ModLoader.exe   <- ЕДИНСТВЕННОЕ, что нужно запускать (менеджер модов с окном)
  SWH2ModLoader\swh2.exe            то же самое из командной строки (не обязательно)
  SWH2ModLoader\*.dll, *.config     служебные файлы загрузчика, не трогать
  Mods\Randomizer\                  рандомайзер наград, врагов, урона, цен
  Mods\Turbo\                       ускорение ходов врагов
  Mods\Challenges\                  челленджи: «без гринда», «без чекпоинтов»
  Mods\CheatMenu\                   чит-меню для миссий
  README.txt                        этот файл

Сами моды — не программы: в их папках нет ничего, что нужно запускать.
Загрузчик находит их сам и применяет к игре.

Установка (один раз)
--------------------
1. Откройте папку игры: Steam -> ПКМ по SteamWorld Heist 2 -> Управление -> Просмотреть локальные файлы.
   Обычно это C:\Program Files (x86)\Steam\steamapps\common\SteamWorld Heist 2
2. Скопируйте туда папки SWH2ModLoader и Mods (с заменой файлов). Должно получиться:
     SteamWorld Heist 2\SteamWorld Heist 2.exe
     SteamWorld Heist 2\SWH2ModLoader\SWH2ModLoader.exe
     SteamWorld Heist 2\Mods\Randomizer\mod.json
     ...
   Копирование само по себе игру не меняет.

Ничего дополнительно ставить не надо: всё работает на .NET Framework 4.8, он есть в Windows 10/11.

Как пользоваться
----------------
1. Закройте игру.
2. Запустите SteamWorld Heist 2\SWH2ModLoader\SWH2ModLoader.exe
3. Слева список модов: поставьте галочки у нужных.
   Выберите мод в списке — справа появятся его настройки (сид, опции и т.д.).
4. Нажмите «Apply to game». Загрузчик сделает бэкап оригинальных файлов игры
   и соберёт игру с выбранными модами. Внизу будет лог.
5. Запускайте игру через Steam как обычно.

Поменять моды или настройки — снова закрыть игру, поправить галочки, «Apply to game».
Каждый Apply собирает игру заново из оригиналов, поэтому изменения не накладываются друг на друга.

Вернуть игру как была — «Restore original files» (или Steam -> Свойства -> Проверить целостность файлов).

Про отдельные моды
------------------
Randomizer
  - Сид: любое число/текст. Пусто — загрузчик выберет случайный и сохранит.
    Один и тот же сид + настройки = одна и та же игра на любом ПК.
  - Нужно НОВОЕ сохранение (в старом поменяются только места, где вы ещё не были).
  - Спойлеры: SWH2ModLoader\Reports\Randomizer\spoiler_<сид>_<дата>.txt

Turbo
  - Ускоряет ходы врагов (по умолчанию x3) и показ врагов/подкреплений (x6). Множители — в настройках.
  - Патчит exe игры, работает только с текущей Steam-версией (загрузчик проверяет сам).

Challenges
  - Каждый челлендж включается отдельной галочкой в настройках мода.
  - «Без чекпоинтов» патчит exe игры.

CheatMenu
  1. Включите мод и нажмите «Apply to game».
  2. Рядом с кнопкой Apply появится кнопка «Cheats…» — откройте окно и не закрывайте, пока играете.
  3. Горячие клавиши (работают в миссии, когда игра в фокусе):
       Ctrl+Alt+1  выиграть миссию          Ctrl+Alt+5  выключить тревогу
       Ctrl+Alt+2  вылечить команду         Ctrl+Alt+6  бессмертие (вкл/выкл)
       Ctrl+Alt+3  убить всех врагов        Ctrl+Alt+7  заморозить врагов (вкл/выкл)
       Ctrl+Alt+4  врагам 1 HP              Ctrl+Alt+8  атаки не заканчивают ход (вкл/выкл)
     Выдать любой предмет — из окна.

Папки, которые создаёт загрузчик
--------------------------------
  SWH2ModLoader\Backup\        оригиналы Game.pak, Game2.pak и exe — НЕ удалять, пока стоят моды
  SWH2ModLoader\profile.json   какие моды включены и их настройки
  SWH2ModLoader\Reports\       логи модов (спойлеры рандомайзера)

Полное удаление: «Restore original files», затем удалить папки SWH2ModLoader и Mods из папки игры.

Командная строка (по желанию)
-----------------------------
Из папки SWH2ModLoader:
  swh2 mods                                  список модов и настроек
  swh2 enable Randomizer Turbo               включить (disable — выключить)
  swh2 set Randomizer seed=12345 damage=on   поменять настройки
  swh2 install                               = «Apply to game»
  swh2 restore                               = «Restore original files»
  swh2 cheat win                             читы (swh2 help — все команды)

Если что-то не так
------------------
  - «Apply» ругается на занятые файлы — закройте игру.
  - Игра обновилась / сломалась — «Restore original files», потом снова «Apply to game».
  - Совсем сломалось — Steam -> Проверить целостность файлов игры.

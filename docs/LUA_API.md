# Lua API движка (извлечено из exe)

Сгенерировано `tools/re/lua_bindings2.py` по `SteamWorld Heist 2.exe` (сборка 2024-10-04).
`impl` — RVA C++-реализации (адрес в памяти = база модуля + RVA). «Вызовов» — сколько раз функция встречается в Lua-скриптах игры;
0 = функция есть в движке, но игра её не использует (неизвестное поведение — проверять в игре).

Плюс функции из `Lua/System/*.lua` (OpenDoor, OpenNamedDoor, …) и базовые: `print`, `LogInfo/Warning/Error`, `RandomInt`, `RandomFloat`, `Color`, `sandbox`, `require`.
